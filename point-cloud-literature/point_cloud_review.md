## 原回复可以保留什么，需要修正什么

可以保留：先用综述建立地图，关注重建与分割，警惕异常索引词。需要修正：

1. **作者关键词不是“最准”的任务判定。**作者关键词可能遗漏任务或用同义词，摘要也可能只在背景中提到任务。应确认本文的输入、输出和主要问题。IEEE Terms可补充召回；某个术语泛化不意味着全部受控词表都不能统计。
2. **当前集合混有非点云研究。**例如记录304《M3-CR: Multiscale Multibranch Mamba for SAR-Assisted Optical Image Thick Cloud Removal》处理卫星影像的云层。作者关键词含Mamba的5条，还包含记录141的事件相机流(x,y,t)方法。不能据此宣称“点云Mamba有5篇”或证明期刊普遍滞后1–2年。
3. **方法词也会误导。**记录28 PointDifformer的neural diffusion指特征/图上的扩散，不等同于生成扩散模型；记录347研究检测网络压缩，568研究高斯表示压缩；614与627是深度图补全。不能把同名词都累计到原始点云任务。
4. **不要由关键词稀少推断发表空间。**记录5 ProtoComp++明确发表于TPAMI，首次在线2026-03-16；记录9和15也涉及TGRS点云补全。样本数量无法推出“补全几乎没有发表空间”，更不能决定选题。ProtoComp++也见[作者发表列表](https://ivg.au.tsinghua.edu.cn/Jiwen_Lu/pub26.html)。
5. **任务、场景、方法是三种维度。**重建/分割/配准是任务；森林/建筑/人体是场景；Transformer/扩散/Mamba是方法。一篇可同时拥有多个标签，计数不可直接相加。所谓“重建最大方向”只是特定词表命中，不能代表全领域排名。
6. **不能把导师组方向当已知事实。**用户没有在当前请求中确认“组里核心做重建”或导师2023年的论文。森林点云方法也可能有可迁移流程；不能凭场景排除一半TGRS。
7. **引用数不决定入门顺序。**通用自监督、图网络、开放词汇、视觉分割综述可以后读；点云专门综述更贴近当前任务。future work是作者建议，需检查后续研究、可获得数据和可复现基线，不能直接当作尚未解决的空白。

## 主流任务的常规流程

| 任务 | 常规流程 | 阅读时重点记录 |
|---|---|---|
| 点云→表面重建 | 获取/标定→去噪采样→多扫描配准（需要时）→邻域/法向（依方法）→显式曲面或隐式场→网格提取/清理 | 输入缺失、噪声和离群点；表面精度/完整度、Chamfer、阈值F-score、法向一致性；闭合性和计算开销 |
| 点云→建筑/BIM/结构模型 | 预处理/配准→语义或实例分割→构件/边缘/平面提取→几何拟合与结构约束→参数化模型 | 结构连接、拓扑、构件识别与模型精度；不能只看视觉效果 |
| 语义分割 | 定义类别/标注→按场景划分数据→分块/采样与特征→点/体素/混合骨干→逐点预测→映射回完整场景 | mIoU及各类IoU、mAcc、OA；多数类会掩盖OA问题；训练测试场景不能混用 |
| 实例分割 | 语义/实例特征→分组或对象查询→实例掩码预测→合并/精化 | 实例AP；全景分割常看PQ，不能与语义mIoU直接混比 |
| 配准 | 两云预处理→局部特征→对应/粗匹配→错误对应剔除→变换估计→局部精配准（可选） | 旋转/平移误差、成功阈值下的召回、重叠率、噪声、运行时间 |
| 点云补全 | 残缺输入及监督构造→特征编码→粗形状生成→点/几何细化→约束与评测 | Chamfer、阈值F-score，有时EMD；可见区域保真、遮挡方式、真实扫描及未见类泛化 |
| 3D目标检测 | 点/体素/柱表示→3D或BEV特征→候选/中心/查询→框和类别预测→后处理 | 明确3D/BEV、IoU阈值、各类别AP、距离与遮挡；与分割输出不同 |
| 连续点云/SLAM | 时间同步/去畸变→帧间运动或里程计→局部地图→回环/后端优化（依系统）→更新地图 | 轨迹误差、漂移、回环、实时性；场景流则评价逐点运动误差 |

这些是帮助对照论文的常规链条，不是所有方法必经的固定步骤。图像→点云的多视图重建还包括相机匹配、位姿/束调整和稠密匹配；纯神经渲染通常以新视角图像质量为主要目标，需单独学习。

## 从这些样本看“前沿在做什么”

先描述问题，再描述架构。以下是本两刊样本里的代表线索，不是全领域热度排行榜。

- **少标注、预训练与开放类别：**PonderV2、SPOT、XMask3D++、PointPDF V2，分别关注通用表示、占据预训练、跨模态开放词汇、持续开放世界。
- **跨尺度/跨传感器/跨域：**BUFFER-X、LPRnet，以及半监督/主动域适应检测，重点是减少目标域标注和调参。
- **真实扫描的几何缺陷：**重建综述、ProtoComp++，关注噪声、缺失、未见类别和合成到真实差异。
- **效率、密度与尺度变化：**HPENet与点云序列化研究，方法价值要结合精度、FLOPs、内存与真实耗时。
- **动态、生成与不确定性：**Motion2VecSets、DifFlow3D及语义点云生成，分别涉及动态曲面、逐点运动和训练数据；不能把各种diffusion词混为一类。
- **完整系统与结构输出：**RR-Net、AdLeaf、TreeStructor、TreeSemantic，展示分割、修复、几何拟合及属性估计如何接成应用流程。

## 粗读的记录与交付

每篇先看摘要、整体流程图、方法概览、实验设置/主表、局限。至少写清六件事：输入→输出；具体问题；完整流程及新增步骤；监督和数据划分；指标/基线/消融；适用条件、代价和失败情形。30分钟可以形成初步地图，不足以保证理解所有细节，更没有“抵20篇”的通用换算。

交给导师的成果建议包含：任务地图；建模与分割各一张可复述的流程图；每个任务2–3篇近期代表作对照；近期瓶颈及其证据。先用第一轮8篇做模板，再扩到正式阅读池，不必把全部记录一口气逐篇精读。

后续按导师实际指定的期刊扩检。若ISPRS、Automation in Construction、Pattern Recognition、JAG确实在导师名单内，再继续补；本次只核实了CSV内的TGRS和TPAMI。正式检索可从point cloud / point-cloud / LiDAR point cloud及任务同义词扩展，区分cloud层、cloud computing、depth completion等异义，避免只搜cloud或只依IEEE Terms。建立候选集后再看题名和摘要，按DOI去重。
