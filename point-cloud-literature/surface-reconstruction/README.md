# 点云表面重建：中文译稿与粗读导读

原文：*Surface Reconstruction From Point Clouds: A Survey and a Benchmark*，Huang 等，TPAMI 2024。DOI：[10.1109/TPAMI.2024.3429209](https://doi.org/10.1109/TPAMI.2024.3429209)。

- [中文译稿 PDF（36 页）](surface_reconstruction_chinese.pdf?raw=true)：正文、图注和作者简介按原文翻译；12 幅图、9 张表、17 个公式保留原图，配中文标题与说明。采用单栏排版，标注原文页码，附 PDF 书签。参考文献保留英文题录。
- [粗读导读 PDF（7 页）](surface_reconstruction_reading_guide.pdf?raw=true)：约 45–60 分钟路线、六类先验、常规重建流程、关键图表、指标与结论边界、三个可选精读部分和粗读笔记模板。
- [在线阅读导读](reading_guide.md)：内容与导读 PDF 对应，可直接在 GitHub 看。

## 怎么用

先读导读中的路线和六个关键图表，再到中文译稿查对应原文页码。第一遍能够说明任务输入输出、方法先验、实验条件和限制即可；之后按[全方向任务地图](../point_cloud_task_map.md)扩展到分类、分割、检测、配准、补全、压缩、动态点云等任务。

## 阅读范围

本译稿用于辅助阅读原论文。图内英文标签、表中数值与方法名保留，中文含义见相邻图注和表说明；不要把导读中的建议当作原文结论。原文提及的在线附录不包含在用户上传的 22 页 PDF 中，译稿也未补写其公式或实验。

原文首次在线发表于 2024 年 7 月 16 日，适合作为基础框架。要了解当前前沿，请配合 2025–2026 年研究论文阅读；论文下载于 2026 年不意味着发表于 2026 年。
