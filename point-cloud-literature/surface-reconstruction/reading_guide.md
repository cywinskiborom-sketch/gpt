## 三、先搞懂任务和一条完整流程

**论文的问题：**给定三维点集，恢复它背后的连续表面。一个点云只是很多坐标；网格还包含连接关系，能明确表示面、边与局部形状。表面本身是嵌入三维空间的二维流形；这里的“二维”指表面局部有两个自由度，不是二维影像。

为什么需要先验？同样的有限点，可以连成许多不同表面。原文第5页公式(1)把目标写成：

> 数据贴合项 L ＋ 权重 λ × 正则项 R。

通俗地说，一方面尽量解释观测点，另一方面限制“允许生成什么样的表面”。只让结果贴点，可能也会贴合噪声；约束太强，则可能抹掉真实细节。

**论文基准中的预处理顺序（V-B，第13页）：**去离群点→去噪→重采样。它使用统计离群点剔除、Jets平滑和FPS；实际算法未必都必须采用这些步骤或同样参数。

**阅读建议：**用下面这条一般流程串起方法，而不是把它背成唯一标准：

> 原始点云及可用扫描信息→检查缺陷、预处理→估计邻域几何/法向及方向→构造数据约束和先验→得到显式表面或隐式场→生成网格→同时检查指标与可视化。

有的方法直接连三角形，有的方法拟合几何基元，还有的方法先学习空间中的函数，再提取表面。分割、配准、补全也可能作为上游步骤；这篇论文主要比较后续的表面重建，并不综述所有这些任务。

## 四、六类先验：记“凭什么补上未知表面”

分类来自Section III的正文，原文并没有一张专门画出全部六类的分类树。以下流程是对各类共同思路的简化归纳，不等于每篇方法都具有完全一样的模块。

| 英文与中文 | 最直白的假设 | 典型数据流与本文例子 |
|---|---|---|
| **Triangulation-based prior：三角剖分先验** | 相邻点可以按几何和拓扑规则连成小三角面。 | 点云→邻接/候选三角形与合法性约束→三角面集合→网格；GD、BPA。干净输入通常更有利。 |
| **Surface smoothness prior：表面平滑先验** | 附近的表面应当平滑，孤立的突变未必是真实结构。 | 点云/法向→局部加权拟合或法向场约束→局部曲面/隐式场→网格；RIMLS、SPSR。过度平滑可能损失细节。 |
| **Template-based prior：模板先验** | 目标能用已知基元或已有形状及其变形来解释。 | 点云→基元识别/模板检索→参数拟合或变形→组合表面；平面、球、圆柱等。能否找到合适模板很关键。 |
| **Modeling prior：模型结构先验** | 选用的函数或网络结构本身就偏向某些几何形状。 | 当前点云→单实例拟合损失和结构约束→参数化曲面/神经隐式场→网格；IGR、SALD等。可不依赖辅助形状训练集，但仍需拟合当前输入。 |
| **Learning-based prior：从数据学习的先验** | 训练形状中存在可迁移的全局类别规律或局部几何规律。 | 辅助形状数据训练→输入点云编码或优化潜码→预测距离/占据等→提取网格；DeepSDF、OccNet、LIG、Points2Surf。需区分全局与局部学习。 |
| **Hybrid prior：混合先验** | 学习能力与几何规则可以结合。 | 点云→学习特征/候选/参数→结合三角剖分、平滑或模板约束→表面/网格；DSE、IMLSNet、ParseNet。 |

最容易混淆的是第四、第五类：**“用了神经网络”不自动等于“从许多形状学习了先验”。** 本文按先验来源区分方法，网络结构带来的约束与训练数据带来的知识可以并存。六类也是按主要先验组织，不应当理解成互不交叉的封闭盒子。

## 五、SDF、UDF、占据场是什么，为什么不是第七类先验？

这些主要回答**“表面怎么表示”**；先验回答**“为什么相信这个表面合理”**。表示形式与先验来源是两个维度。

- **SDF，有符号距离函数：**对空间查询点输出到表面的距离，并用正负区分内外；表面对应零水平集。内外的正负约定看具体方法，不需要现在背符号。
- **UDF，无符号距离函数：**输出距离而不提供内外符号。第8页以MeshUDF说明它可支持开放表面；提取网格需要适配算法，不应直接套用有符号场的所有处理。
- **Occupancy field，占据场：**描述空间点在形状内部或外部的状态/概率，表面是占据状态的边界；它不是距离值，也不应一律说成“取零值表面”。
- **显式表示：**直接给出表面参数映射或网格等；**隐式表示：**先定义空间函数，再从函数提取表面。

例如，SDF既可以由单实例优化得到，也可以用辅助训练数据学习得到。因此“隐式＝深度学习”“SDF＝学习先验”都不成立。

## 六、五种扫描缺陷：看结果时先诊断输入

| 缺陷 | 原文含义与直观表现 | 阅读时追问 |
|---|---|---|
| **Point-wise noise：逐点噪声** | 点独立偏离真实表面，局部像抖动。 | 平滑去噪后，细边缘是否也被抹平？ |
| **Non-uniform distribution：密度不均** | 不同区域因距离、多次扫描等具有不同密度。 | 邻域尺度、采样和特征聚合是否适应稀密变化？ |
| **Point outliers：离群点** | 少量点明显远离真实表面。 | 预处理后还剩多少？重建是否产生孤立碎片或错误表面？ |
| **Misalignment：扫描错位** | 多视点部分点云因位姿误差没有准确叠合。 | 是否生成增厚/双层表面？应先改进配准还是让重建抵抗错位？ |
| **Missing points：缺失点** | 遮挡、反射或视角覆盖不足导致部分表面无观测。 | 填的是正确结构还是仅封住洞？补全假设来自哪里？ |

**论文报告：**对象合成数据控制不同缺陷和严重度；场景数据同时包含多种缺陷。真实数据可能混合这些问题。**阅读建议：**别用“鲁棒”两个字结束笔记，要写清对哪种缺陷、哪种严重度有效。

## 七、四种指标：先理解量什么，再谈谁更好

正文第13—14页说明指标用途，但将确切计算式放在**在线补充材料Appendix B**。当前这份PDF没有该附录，因此本指南不冒充已经核验具体公式、采样数或F-score阈值。

| 指标 | 中文与正文说明 | 比较方向与限制 |
|---|---|---|
| **CD** | Chamfer Distance，倒角距离；用于判断两个形状整体的几何接近程度。 | **越小越好。** 留意归一化、采样与表头倍率，不能把数值直接当作实际毫米误差。 |
| **F-score** | F分数；本文与CD一起衡量整体形状相似性。 | **越大越好。** 通常涉及距离阈值下的准确与覆盖，但本文具体阈值应查Appendix B，跨论文不可只比裸数。 |
| **NCS** | Normal Consistency Score，法向一致性得分；关注相似形状的局部法向一致程度。 | **越大越好。** 与CD不是同一件事；不能把它直接当作“洞是否填对”的充分证明。 |
| **NFS** | Neural Feature Similarity，神经特征相似度；在深度特征空间比较形状的语义/感知相似性。 | **越大越好。** 它不是“法向F分数”；具体网络、特征层和计算应查附录。 |

升降方向可从第15页表头确认。公平阅读至少检查：是否用相同输入与预处理，是否提供法向/扫描位姿，训练集是否含同类形状，参数如何选择，属于对象还是场景，评价参考如何获得。本文对不同方法调参，比较条件需一并记录，不能只搬某一列冠军。

## 八、论文报告了什么，能推广到哪里？

**原文实验发现（VI，第14—18页）：**

1. 在所比较方法和基准条件下，缺失区域仍难正确恢复；错位和离群点也令多数方法不满意。一些隐式方法封洞形成的凹/凸包，并不代表真实结构恢复成功。
2. 一些不依赖辅助训练数据的方法，尤其SPSR，在复杂形状的泛化和鲁棒性上表现良好；全局语义学习方法受训练类别限制，局部学习方法更适合组合复杂场景。
3. 数据驱动方法并非没有优势：在较严重的数据缺陷条件下体现一定鲁棒性，训练集中有同类对象时也能较好恢复。这不能简化成“传统方法全面胜过深度学习”。
4. 正确朝向的法向有帮助；在其相机位姿辅助实验中，内外方向是否正确比法向估计有多精确更关键。
5. 不同指标可能不一致，CD/F-score良好也可能伴随局部增厚、多层或不自然表面。

**结论边界：**基准收集1620个合成对象，但对象比较使用其中**22个对象、308对输入—输出**；另比较50个合成场景和20个真实扫描对象。正文没有把六类所有方法逐一实测；纯模板方法未单独纳入比较。不要把“本文条件下难解决”写成“整个领域到2026年仍然无人解决”，也不要将某些方法的结果无条件扩大到全部深度学习。

**我的建议：**把“缺失、错位、离群、训练分布变化、评价与视觉不一致”写成后续检索的问题清单。再查2024年10月以后论文有哪些新证据，而不是将综述中的未解决问题直接当成已确定的选题空白。

## 十二、之后要扩大方向，不要停在建模

下面是**阅读建议，不是本文的综述覆盖范围**。先为下面十个任务组各选一篇任务明确、流程与实验清楚的入口，再从感兴趣的任务补4—8篇窗口内的新问题/新方法，第一轮约14—18篇；无需每篇精读。森林、植物、建筑、室内或自动驾驶都是场景，应按任务相关性判断。

| 方向 | 第一遍先回答的流程问题 |
|---|---|
| 分类/识别 | 整个对象点云→特征→一个类别；与逐点地物分类有何不同？ |
| 语义/实例/全景分割 | 点云→多尺度特征→逐点类别与对象实例；实例掩码或聚类在哪一步？ |
| 三维目标检测 | 点/体素/BEV特征→候选或查询→三维框；怎样处理稀疏和远距离目标？ |
| 配准/定位/SLAM | 对应匹配→鲁棒变换→细化；连续扫描怎样加入定位、回环与地图优化？ |
| 表面/结构重建 | 点云→几何约束与表面表示→网格或结构模型；本综述是这个任务组的入口。 |
| 点云补全 | 缺损点云→可见部分表征与形状先验→完整点云；怎样验证缺失几何的合理性？ |
| 去噪/法向/上采样 | 带噪或稀疏点→邻域几何→清洁点、法向或密集点；细节是否保真？ |
| 点云压缩 | 坐标/属性→预测、量化与熵编码→码流→解码；码率与失真怎样权衡？ |
| 动态点云 | 多帧点云→对应与时序表征→逐点运动或目标轨迹；场景流与跟踪的输出有何区别？ |
| 三维变化检测 | 不同时期点云→配准与跨时相比较→变化位置/类别；怎样排除错位造成的假变化？ |

预训练/自监督、少标签、多模态、开放词汇和泛化属于横向方法；分别看它们改变以上哪个任务的训练或推理环节。建筑、森林、室内等是应用场景，不能与任务直接混排。

所有论文用同一张笔记模板，最终形成“任务→输入输出→共同步骤→近期变化→数据与评价”的领域地图。这比先把一篇长综述完全精读，更贴合导师要求的广泛粗读。
